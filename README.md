## 🚀 Overview

YATRI.in is a travel-focused web platform designed to make trip planning easier and smarter.  
It helps users explore destinations, manage travel preferences, and improve the overall journey experience.

---

## ✨ Key Features

- 🌍 Smart destination discovery  
- 🛕 Pilgrimage & tourism planning  
- 🔐 Secure login system  
- 📱 Responsive user interface  
- ⚡ Fast and lightweight experience  
- 🤖 Scope for AI-based recommendations
