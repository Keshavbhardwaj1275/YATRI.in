## 🚀 Overview

YATRI.in is a travel-focused web platform built to make trip planning easier, faster, and smarter.  
It helps users explore destinations, manage travel preferences, and improve the overall travel experience.

---

## ✨ Key Features

- 🌍 Smart destination discovery  
- 🛕 Pilgrimage & tourism planning  
- 🔐 Secure login system  
- 📱 Responsive user interface  
- ⚡ Fast and lightweight experience  
- 🤖 Future AI-based recommendations
